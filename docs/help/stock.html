Stock verification

Stock verification compares scanned barcodes with a fixed collection snapshot. One open session is allowed per library.

How to use this section

  1. Open Stock verification and create a named session for the selected library.
  2. Scan copies against the session. Repeated scans do not add duplicate expected records.
  3. Review seen and unseen items, especially copies that were already on loan at session start.
  4. Investigate discrepancies before closing. Confirm closure and inspect resulting copy statuses.
  5. Export findings for approval. Correct later copy status through Catalogue with a reason.

Notes and limits

The expected inventory is fixed at session creation; reconcile later acquisitions and circulation separately.

Do not classify every unscanned item as permanently lost without physical and circulation checks.
