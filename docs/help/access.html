Operator & administrator manual

Accounts, roles & institution access

Live accounts use Supabase email/password authentication. Create or invite a user through the trusted Supabase dashboard. Administrators reset assigned accounts in Settings > Institution access > Reset password. Each user can choose Change my password in the sidebar. Both actions require the current password of the person performing the action; see Password management for detailed steps. Never share one account among operators when audit attribution matters.

RolePermissions
AdminAll workflows, policies, holidays and institution-role assignments.
LibrarianCatalogue/patrons/imports, desk, fines, acquisitions and stock; read settings.
AssistantIssue, return, renew and manage holds; read institution records and reports.
AccountantRecord payments/waivers and read records/reports.
AuditorRead institution records, reports and audit; no writes.
PatronRead catalogue and own loans/holds/fines; renew own loans and manage own holds.

Assign a membership

  1. Select the intended campus using the top-right institution selector.
  2. Open Settings > Institution access > Assign role.
  3. Enter the existing Supabase Auth user UUID and a role.
  4. For a patron role, select that institution's linked patron record. This is required. A staff role may omit the link.
  5. Save, then ask the user to sign in again or refresh their session/workspace.

Users only see institutions in their memberships. A user may be admin in one campus and auditor in another. Admin cannot change their own role through this UI. To revoke a membership entirely, a trusted operator uses SQL Editor to delete the appropriate app.memberships row; role reassignment is available in the UI. Preserve at least one authorised administrator.

Patron profiles and Auth accounts are separate: bulk student upload creates library patron records, not passwords or Auth users. Link accounts later when patron self-service is required. Staff read permissions currently include patron contact data; assign roles accordingly.
