Reports and saved definitions

Reports provide CSV exports and a safe dataset/date report builder. Arbitrary SQL is never accepted from the browser.

How to use this section

  1. Export Loans, Catalogue, Patrons, Fines, Payments or Acquisitions as available in Reports.
  2. Inspect Most borrowed titles for recorded checkout totals, including returned issues.
  3. Create a named report for loans, copies, patrons, fines, acquisitions or serial_issues, with optional date bounds.
  4. Run it, inspect the first 100 rows and download CSV for all results.
  5. Dates apply to loan issue dates, acquisition order dates and serial expected dates. Copies, patrons and fines are current snapshots and ignore date bounds.

Notes and limits

Staff reporting is restricted to assigned libraries. Patron accounts cannot run staff reports.

Report scheduling, emailed outputs and Koha's arbitrary SQL editor are not implemented. Protect downloaded data.
