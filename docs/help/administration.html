Administration and audit trail

The network administrator manages the four libraries. Authorization is checked on each database/API request.

How to use this section

  1. Select the correct library before changing policies, holidays or assignments in Settings.
  2. Create staff using real email addresses and unique temporary passwords. Creating a librarian also assigns that library's primary librarian.
  3. To replace a librarian, use Assign librarian with the existing Auth UUID and display name. The former primary librarian membership is removed from that library.
  4. Assign assistant, accountant, auditor or linked patron memberships in Institution access. Another network admin cannot be created here.
  5. Open Audit trail, search by action/actor/details, expand stored details and export authorized records.
  6. Review availability changes, account operations, imports, returns and fine waivers in particular.

Notes and limits

The administrator email is fixed in the account UI. An administrator-identity change requires deliberate trusted database maintenance.

Audit records have no user-facing deletion. Passwords are not stored in audit details.
