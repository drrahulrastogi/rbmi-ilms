Holds and reservation priority

Holds reserve a bibliographic title within a library, using a FIFO waiting queue ordered by creation time and identifier.

How to use this section

  1. Choose Holds > Place hold, or Place hold in a title's copy drawer. Select a title and enter an active, unexpired patron code.
  2. Review queue position, placement time and status. The same patron cannot have duplicate waiting holds on the same title.
  3. Issue the next available copy to the first waiting patron. The server blocks queue bypass and marks the hold fulfilled when issued.
  4. Cancel unwanted waiting holds. Staff manage the library queue; patrons manage only their own holds.

Notes and limits

A waiting hold blocks renewals of that title.

Pickup-expiry timers, automatic notification emails and inter-library transfers are not implemented. Use the approved institutional contact procedure.
