MARC book migration

Catalogue > MARC migration supports UTF-8 ISO2709 .mrc and MARCXML .xml files, supplementing CSV and the controlled Excel import.

How to use this section

  1. Prepare a UTF-8 file up to 10 MB and 1,000 physical copies. Convert MARC-8 through your cataloguing tools first.
  2. Map 245 title, 100/110/700 author, 020 ISBN, 260/264 publisher/year, 650 subject and 082 classification.
  3. Items use 952$p barcode, 952$i accession or barcode fallback, 952$a/$b library, 952$c shelf and 952$g price.
  4. Select the file, review its preview and confirm the checkbox. Item library must match the selected workspace; RBMI is an alias for shared RBCET.
  5. Import and inspect copy counts and identifiers. Invalid records, duplicate barcodes or cross-library items reject the whole batch.

Notes and limits

This is targeted MARC import, not a complete MARC editor, MARC-8 converter or lossless MARC export service.

Invalid record lengths, directories and terminators are rejected. XML document types and entities are prohibited.
