Patrons, faculty and institute assignments

Patrons are borrowing memberships, separate from Auth users. All supplied RBCET student files are assigned to the shared RBCET/RBMI library.

How to use this section

  1. Open Patrons and search by name, code, category or department. Source card number is the patron code; roll number is used when no card number was supplied.
  2. Expand View profile to inspect supplied roll/card numbers, institute, course, branch, year, semester, admission date, mobile, email, gender and birth date where present.
  3. To add faculty individually, select the library, choose Add patron, set category Faculty and choose the institute. RBCET and RBMI share one library but remain separate institute choices. Enter the faculty employee/patron code, name and department, then save.
  4. Add patron requires unique code, name, category and active status. Email, department/class and expiry are optional.
  5. To edit a membership, retain its existing code. The core editor changes name, email, category, department, active flag and expiry; uploaded additional profile fields remain preserved.
  6. Deactivate or expire memberships when borrowing must stop. Preserve their loan history. Export CSV only for authorized institutional work.
  7. Patron search runs against the database. Use Previous / Next beneath the table to browse 50 matching records per page. CSV export reads every matching page, not just the visible rows.

Notes and limits

Source blanks remain blank. No birth dates, contact information or expiry dates are invented.

Student and faculty bulk imports create linked patron logins when a unique real email is supplied. Student profiles and source archives are private and never appear in anonymous OPAC responses.

Faculty memberships use faculty circulation policies. Bulk uploads create linked Patron-role accounts; individual Add patron creates only the borrowing membership.

Student and faculty library cards

  1. In the assigned library, open Patrons and search for the student or faculty member.
  2. Choose Print card on that person's row. Verify the name, patron code, category, department, institute and expiry.
  3. Upload a PNG, JPEG or WebP photo up to 4 MB, or focus the preview and paste an image. The photo is kept only in that print preview.
  4. Alternatively leave the dashed photo box blank so a printed photograph can be pasted onto the card.
  5. Choose Print card / Save PDF. Print at actual size / 100% to retain the 86 mm card width. The barcode represents the patron code.
