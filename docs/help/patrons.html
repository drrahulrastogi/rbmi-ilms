Patrons and student profiles

Patrons are borrowing memberships, separate from Auth users. All supplied RBCET student files are assigned to the shared RBCET/RBMI library.

How to use this section

  1. Open Patrons and search by name, code, category or department. Source card number is the patron code; roll number is used when no card number was supplied.
  2. Expand View profile to inspect supplied roll/card numbers, institute, course, branch, year, semester, admission date, mobile, email, gender and birth date where present.
  3. Add patron requires unique code, name, category and active status. Email, department/class and expiry are optional.
  4. To edit a membership, retain its existing code. The core editor changes name, email, category, department, active flag and expiry; uploaded additional profile fields remain preserved.
  5. Deactivate or expire memberships when borrowing must stop. Preserve their loan history. Export CSV only for authorized institutional work.

Notes and limits

Source blanks remain blank. No birth dates, contact information or expiry dates are invented.

Importing students does not create login accounts. Student profiles and source archives are private and never appear in anonymous OPAC responses.
