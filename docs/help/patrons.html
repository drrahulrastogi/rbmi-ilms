Patron registration & membership

Open Patrons > Add patron. Required values are patron code, full name and category. Categories are student, faculty, staff, alumni and guest. Optional fields include email, department/class, active flag and expiry date.

Patron codes are unique within each institution. Use stable codes from the student/staff register. Edit keeps the same code to update that membership. Changing the code creates a separate record; the help form warns about this. An inactive patron or a patron whose expiry is before today's India date cannot receive a new issue, renew or place a hold. The expiry date itself remains valid.

The active-loan count shows open loans only. Contact email is informational; no automatic email delivery is configured in this release. Categories select the appropriate circulation policy. If an administrator changes a category, existing loans retain their original policy snapshot and new loans use the new category's policy.

To suspend borrowing, edit Active to unchecked and save. Do not remove records with loan history. For a graduating student, review active loans and assessed fine balances before suspending membership and issuing an institutional clearance outside the software.
