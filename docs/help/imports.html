Bulk uploads and the supplied Excel import

The supplied workbooks were processed through a controlled administrative import. Regular application Bulk upload uses UTF-8 CSV, with preview and confirmation before a transactional batch.

How to use this section

  1. Choose the correct library. Open Catalogue > Bulk upload for books, or Patrons > Bulk students / Bulk faculty, then download its template.
  2. Books require title, author, accession and barcode. Optional fields include ISBN, publisher, subject, classification, year, shelf and price. One row creates one physical copy.
  3. Student CSV requires code and name; optional email, category, department, active and expires. Additional profile columns can be preserved through student imports.
  4. Faculty CSV requires code and name. Set category to faculty; institute must belong to the selected library (RBCET or RBMI for the central library, otherwise RBCP, RBCN or RBGN). Optional columns include email, department, active and expires. Existing faculty codes update memberships; a code already used by a student or another category is rejected. Review the preview and approve the batch.
  5. Export Excel as UTF-8 CSV without converting identifiers into scientific notation or losing leading zeros. Use no more than 1,000 rows and 5 MB per batch.
  6. Review errors and the first eight rows, confirm the checkbox and import. A failed row rolls the entire batch back.
  7. Existing patron codes update core memberships. Duplicate book barcodes/accessions reject the batch. Review updates carefully; blank expiry clears it and blank active defaults to true.
  8. The owner-provided import prepares 278 students and 26,071 book copies. One book row missing a barcode or title is held in the private review report. Original workbooks remain unchanged.

Notes and limits

Protected archives retain source hashes, sheet names, row numbers and original fields. The BSCS sheet's incomplete header was mapped to the common 15-column book layout after inspection.

Missing authors use Unknown author. Missing or nonnumeric prices use zero operationally while retaining the original value in source details. Historical loans are not inferred from a stock list.
