Operator & administrator manual

Bulk books & student CSV upload

  1. Open Catalogue or Patrons and choose Bulk upload.
  2. Download the corresponding template.
  3. Save your data as UTF-8 CSV with a header row, maximum 1,000 rows and 5 MB per file.
  4. Select the file. Review validation errors and the first eight rows in the preview.
  5. Check the review confirmation and Import.
  6. Confirm the success count. On an error, no row from that batch is committed.

Book columns

Required: title, author, accession, barcode. Optional: isbn, publisher, subject, classification, year, shelf, price. One row represents one physical copy. If a non-empty ISBN already exists in the same institution, its bibliographic record is reused and the incoming metadata does not overwrite it. Blank ISBN makes a new title record; use the manual title/copy workflow to attach copies to an existing no-ISBN title.

title,author,isbn,accession,barcode,shelf,price
Learning React,Alex Banks,9781492051725,A2026-01,RBCET-A2026-01,C-2,650

Student/patron columns

Required: code, name. Optional: email, category, department, active, expires. Blank category defaults to student. active accepts true/false; blank defaults to true. expires uses YYYY-MM-DD or blank. An existing campus patron code updates the record. Blank expiry clears a previous expiry; blank active reactivates. Include those fields explicitly when updating an existing register.

code,name,email,category,department,active,expires
RBCET-S101,Example Student,,student,BTech Year 1,true,2027-06-30

CSV quoting follows normal CSV rules: quote fields containing commas/newlines/double quotes, double embedded quote characters. Preserve codes/ISBNs as text in Excel to prevent lost leading zeros. Client validation is a convenience; the PostgreSQL transaction remains authoritative. Existing barcode/accession conflicts or invalid data reject the entire batch. Uploaded student records do not create Auth accounts.

CSV exports prefix spreadsheet-formula-like text values with an apostrophe to reduce formula execution when opened in spreadsheet software.
