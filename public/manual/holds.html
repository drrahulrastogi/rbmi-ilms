Reservations & hold queue

Open Holds > Place hold, or View copies > Place hold. Choose a bibliographic title and enter the patron code. For patron self-service use the linked profile's code. Active and unexpired membership is required. A patron may have only one waiting hold per title.

Waiting holds are served in creation order, with UUID as the stable tie-breaker for equal timestamps. The first waiting patron has priority over every available copy of that title. If another patron tries to issue it, the server reports that it is reserved. Issue to the first patron changes that hold to fulfilled. Subsequent copies can serve the next waiting patron.

Any waiting hold blocks renewals on the title, including a hold by the same borrowing patron. Cancel a waiting hold using the Cancel action. Patrons can cancel only their own. Fulfilled/cancelled records remain visible in history.

This release does not send notification messages or enforce automatic hold pickup expiry. Librarians monitor the queue and cancel stale requests according to institution policy. Holds can be placed even when copies are available, allowing desk-managed reservation workflows.
