Windows CHM source

The delivered help project contains RBMI.hhp (project/options/file list), RBMI.hhc (contents tree), RBMI.hhk (keyword index), standalone HTML topics and local CSS assets. It does not need the React server or a database to read.

  1. Install Microsoft HTML Help Workshop from an approved Microsoft source. Its compiler executable is hhc.exe, distinct from the Windows hh.exe viewer.
  2. Open PowerShell in the project directory.
  3. Run .\scripts\build-chm.ps1 or pass the full compiler path with -Compiler.
  4. Open the newly generated docs/help/RBMI.chm in Windows. Test Contents, Index, Search and internal links.
.\scripts\build-chm.ps1 -Compiler 'C:\Program Files (x86)\HTML Help Workshop\hhc.exe'

The build script requires a newly produced nonempty output; it does not assume an exit code alone proves success. If Workshop is unavailable, use index.html/printable.html and your browser's Print > Save as PDF. A compiled CHM was not created in the build environment because no compiler was installed.

If a downloaded CHM opens with blocked content, extract it to a local trusted folder and use Windows file Properties > Unblock if available. Do this only for the help file you trust. HTML topics remain an alternative on platforms without CHM support.
