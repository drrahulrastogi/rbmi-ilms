Operator & administrator manual

Local installation & demonstration

  1. Install Node.js 20.16 or newer. A current supported Node LTS is preferred.
  2. Extract the ZIP into a local folder. Open PowerShell in the extracted project folder.
  3. Run npm ci to install the locked dependencies.
  4. Run npm run dev. Open the Vite URL, normally http://127.0.0.1:5173.
  5. Keep both Supabase environment variables empty to use sample data. The first load downloads roughly 14 MB of browser PostgreSQL runtime and may take several seconds.
npm ci
npm run dev
# Production build
npm run build
npm run preview

The Windows shortcut scripts/start-windows.cmd checks Node, installs packages and starts Vite. Development uses a server: do not double-click the built index.html through a file URL.

Persist or reset the demo

Records persist in IndexedDB on the same browser origin. Closing the page does not remove them. A different port/origin starts a separate database. In browser Developer Tools, Application/Storage, delete the IndexedDB database rbmi-library-v1 for this origin, then reload to regenerate the sample. Never enter real patron data into the local demonstration.

Verification commands

npm test
npm run build
npm run preview
# Second terminal, with Chrome installed:
npm run test:ui

Database tests use the actual PostgreSQL migration and RPCs through PGlite. Browser tests start fresh sample data in headless Chrome. Tests do not prove live Supabase Auth integration, multi-user stress behavior or printer compatibility; verify those in the institution environment.
