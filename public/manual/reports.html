Reports and saved definitions

Reports can be viewed inside the application or downloaded as PDF or CSV. Every report uses the selected library. Standard reports cover the collection, circulation history, overdue loans, fines, patrons, acquisitions and most borrowed titles.

How to use this section

  1. Select the correct library at the top, open Reports, and choose View report on a standard report card. The report opens on the same page; downloading a file is optional.
  2. Use Search this report to narrow the rows. Choose 25, 50 or 100 rows per page and use Previous page / Next page. Use the horizontal scrollbar to read columns that extend beyond the screen.
  3. Select Export PDF or Export CSV in the open report to export every matching row across all pages. Export buttons on a report card download the complete unfiltered report.
  4. PDF includes the library code/name, report title, generation time in IST, row count, repeated column headings and page numbers. Wide tables can continue columns on another page; use the repeated # column to match rows.
  5. For large PDFs, a progress message shows pages prepared. You can keep using the page or select Cancel PDF. Search before exporting if you only need a subset of records.
  6. To create a saved report, select Create report, enter its name and dataset, and optionally set From / To dates. Date limits apply to loans, acquisitions and journal issues. Collection, patron and fine datasets are current snapshots.
  7. Choose Run / view report beside a saved definition. Its results open in the same viewer, with search, pagination, PDF and CSV options. Applied date limits also appear in the PDF.
  8. If no records match, the viewer states that clearly and PDF exports show zero matching records. Refresh data using the main refresh button after colleagues make changes.

Notes and limits

Exports include all matching records, not just the page on screen. Search is across the displayed report columns.

Complete reports are fetched on demand through bounded database pages; the smaller workspace preview is never used as a complete register. CSV and PDF contain the same matching rows and exclude passwords and authentication secrets.

PDF files are prepared in the browser. Completed exports can contain private institutional records; share them only with authorized people.

Report preparation can be cancelled. Exports stop with an explicit error if a dataset exceeds 50,000 records; use a saved report with narrower dates instead of accepting a partial file.
