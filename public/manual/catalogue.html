Operator & administrator manual

Catalogue, accessions & barcode labels

  1. Open Catalogue and choose Add title.
  2. Enter required title and author; add ISBN, publisher, subject, classification/DDC and year when available.
  3. Open View copies on the title card.
  4. Choose Copy. Enter accession number and barcode; optionally shelf and price.
  5. Print the copy's label and affix it to the physical item. Label uses scanner-compatible Code 128.

Each physical copy must have its own barcode. Barcode uniqueness is global; prefix with campus code, for example RBCET-A-2026-001. Accessions are unique within a campus. Adding a bibliographic title alone does not create a copy. Search accepts title, author, ISBN, subject, DDC, accession and barcode.

Edit and change condition

View copies > Edit title updates bibliographic metadata. A copy's Status action allows available, lost, damaged, withdrawn or missing, with a mandatory reason. A currently loaned copy must first be returned before a manual state change. All changes are audited. Copies are retained rather than deleted, preserving loan history.

Withdrawn copies are excluded from a newly started stock session. Lost/damaged/missing copies remain visible for investigation. Returning an item makes it available; if it needs repair, immediately change status to damaged with a reason. Marking a lost copy does not post a replacement charge automatically.

Printer/scanner setup

Use a USB barcode scanner configured as a keyboard wedge and set its suffix to Enter if appropriate. Focus the barcode input before scanning. Use barcode values printable in Code 128 (ordinary ASCII recommended). Label opens a popup; allow popups for this trusted app if the browser blocks it. Print at actual size and test scanning before mass printing.
